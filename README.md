## 🧠 Problem-Solving Approach

1. Understand the requirements and identify edge cases.
2. Create a simple brute-force solution.
3. Analyze time and space complexity.
4. Optimize using suitable data structures and algorithms.
5. Test normal, boundary, and invalid inputs.
6. Refactor the code for readability and maintainability.
